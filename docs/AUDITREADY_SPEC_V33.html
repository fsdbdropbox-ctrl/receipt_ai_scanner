De "Escáner" a "Bóveda"

El acceso no es solo login; es el contrato de seguridad. Se elimina el escaneo anónimo. El usuario debe percibir que entra en una "bóveda administrativa", no en una utilidad desechable.

Captura Personalizada

Interfaz especializada en documentos. No es la cámara estándar del sistema.

  • Recorte Automático: Detección de bordes en tiempo real para eliminar fondos irrelevantes.
  • Auto-disparo: Detecta cuando el documento está quieto y enfocado.
  • Modo Multi: Escaneo continuo de varias páginas sin salir de la cámara.

Menú Contextual (Overlay)

Punto de entrada unificado accesible desde el Tab Bar. Permite elegir la fuente de la verdad antes de procesar.

Accesibilidad: Este menú atrapa el foco del teclado y permite cerrar con Escape o clicando fuera (Backdrop).

Selección de Lote

Selector nativo tipo grid que permite escoger múltiples imágenes de la galería de una sola vez.

  • Indicadores visuales de orden de selección (1, 2, 3...).
  • Interactividad: Prueba a hacer clic en los recuadros para seleccionarlos/deseleccionarlos.
  • Confirmación explícita con botón "Añadir".

Opciones de PDF

Paso crítico de desambiguación para archivos importados.

Un solo documento

Para facturas multipágina (ej. factura de teléfono de 3 págs).

Separar páginas

Para PDFs escaneados que contienen múltiples tickets distintos.

Procesamiento (Queue)

Gestión asíncrona de subidas. Permite ocultar el proceso y recibir una notificación al completar.

Lógica de Segundo Plano:
  • Si el usuario pulsa "Ocultar", mostramos un Toast persistente.
  • Si el usuario espera, la pantalla navega automáticamente al Resumen de Lote.

Resumen de Lote

Punto de control tras la ingesta masiva. El usuario decide qué hacer a continuación.

  • Completos: Archivados automáticamente
  • Incidencias: Requieren revisión manual

Auditoría Expandida (Review)

Ya no es un simple resumen. Es una ficha completa de datos fiscales para cumplimiento normativo (ES-21).

Campos Críticos Añadidos:

  • NIF Emisor: (B1234...) Identificación fiscal del proveedor.
  • NIF Receptor: (B9876...) Validación cruzada para deducibilidad.
  • Desglose: Base Imponible + Cuota IVA + Tipo (%).
  • Etiquetas: Clasificación analítica (Proyecto, Cliente).
Compliance: Eliminada cualquier referencia a "Deducción". El lenguaje es estrictamente sobre "Integridad de Archivo".
